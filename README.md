# Sawad portfolio (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

- `src/data.js`  – all your text content (projects, certifications, experience, tools, blog)
- `src/App.jsx`  – page layout and sections
- `src/icons.jsx` – SVG icons
- `src/App.css`  – styles and colors (CSS variables at the top)
